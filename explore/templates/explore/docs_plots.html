Plots page

The Plots tab lists every component type with items; a type's page plots distributions over its items' Item Specifications or Test Results. The left panel has three panes — Data, Cuts, Series — the chart sits on the right with an items grid below it. The whole configuration lives in the page URL: Copy link shares a plot, Save as… keeps it in this browser.

Data

The source select offers Item Specifications and one entry per test type that has records in the mirror, with its item count.

  • Item Specifications are fetched from HWDB into this browser when you first open the page (automatically up to 1,000 items, on request above that) and kept there; Refresh fetches them again. The status line says when they were fetched.
  • Test data is read from the server's mirror, which is filled by a sync: fetch test data from HWDB… in the select (or Fetch new) reads the latest test record of every item not yet mirrored; Refresh all re-reads every item. The sync's log shows under the pane. A type whose tests were never synced has no test entries in the select.

A test type's keys carry their list shapes (a badge with the length in the key picker), so indices apply. Keys present on fewer than 5% of items hide behind the picker's rare box.

Below the source, the Draw lines and the X / Y key pickers describe what the highlighted series plots; Mode, Bins, log y and stats are shared by all series.

Cuts

Cuts pick items for the highlighted series; every filled box must match.

BoxMatches
Itemexactly one PID — clicking a row of the items grid fills it, clicking again releases it
PIDa substring, a regular expression, or a range of the numeric suffix: 00120..06000, 00120.., ..06000, also with the type prefix D00400300001-00120..06000
Seriala substring or a regular expression on the serial number, case-insensitive: HPK.*

On values+ cut adds key · operator · value: = ≠ < ≤ > ≥ compare numerically when both sides are numbers, else as text; contains is a case-insensitive substring. A list key passes when any entry does. Match = all cuts or any cut.

Cuts keep or drop whole items. To keep single entries of a list, use the Draw pane's Select.

Series

A plot holds one or more series over the same source. + series adds a copy of the highlighted one; the chips above the chart and the list in the pane switch the highlight; the list also renames a series, sets its colour, and removes it. The Draw lines, key pickers and Cuts edit the highlighted series only. A dimmed chip is a series the current mode does not draw.

Limitstolerance lines: dotted at each value, across a value plot or upright on a histogram, with the axis stretched to show them. The select reads the two boxes as absolute values, as mean ± value or mean ± % of the highlighted series' plotted values; the line labels spell out the result

Drag a box to zoom, shift-drag to pan, double-click or Reset zoom to reset. ⤓ PNG saves the picture. The stats box gives Entries, Mean and Std Dev per numeric series; off, a plain legend remains. Hovering a point names its item (PID and serial) and the entry's index. The items grid under the chart lists the dataset's items with a filter box; a click plots that item alone.

Sharing

  • Copy link copies the page URL, whose # part holds every setting — source, series with their keys, cuts and selections, mode, bins, ranges, limits, labels. Opening it on another server of the explorer works, since only the type and the state are in it; the data is fetched there.
  • Save as… stores the URL under a name in this browser; Load ▾ lists them, Save overwrites the loaded one. The Plots tab lists all saved plots of this browser at the top. Nothing is stored on the server.
  • A checklist's plot field embeds this page for the items named in the form (see the checklist editor guide); its Open in Plots opens the full page with those items as a PID filter.

Draw

The Draw pane reads ROOT's TTree::Draw(expression, selection, option): the Draw line is the expression, Select the selection, Option the third argument, over the keys of the current source. Enter applies a line; Shift+Enter breaks it; the Draw button applies all three. An error shows under the line, with a 1-based character position.

Expression

One expression draws its histogram. Two, separated by a colon, draw two axes — the first is Y, as in ROOT. One colon at most. An expression's result is a number; text keys are plotted by picking them in the X field below the pane.

Result[3]                      histogram of the 4th Result of every item
Result_Err[3] : Result[3]      Y = Result_Err[3] against X = Result[3]
sqrt(Result_Err[3]) : Result[3]  any expression on either side

A plain key name (with or without indices) is the same as picking that key in the X / Y fields below the pane; the page writes the picked keys back into the Draw line, so the two stay in step.

Keys

A key is its path in the record, segments joined by dots: Test_Results.SiPM.Result. The trailing segments are enough when they name one key — SiPM.Result, or just Result.

RuleExample
Spaces in a name are written as _Test_Results for “Test Results”
Other characters: quote the segment with double quotes"Vbd (V)", SiPM."Result-A"
Case does not matterresult finds “Result”
… unless two keys differ only by case or spacing — then the exact spelling decidesVbd vs VBD
Several keys still match: the error lists them, add a segment“Result” matches 2 keys: … → SiPM.Result

Indices

Some levels of a record are lists — the tree shows their length in a badge. Brackets pin one entry of a list level, counted from 0; a level without a pin plots every entry. Take a record of the shape Test Results (a list of runs) › SiPM (a list of 8 boards) › V (a list of 3 voltages):

WritePlots
Vevery voltage of every board of every run
V[0]the first run's — the leaf's brackets count list levels from the outermost, as ROOT's a[i][j]
V[0][2]the first run, the third board, all three voltages
V[][2] or V[*][2]the third board of every run — an empty bracket skips a level
SiPM[2].Vbrackets on an inner segment pin the level that segment names: the third board, every run
SiPM[2].V[0]the same as V[0][2]: the leaf's brackets always count from the outermost level, whatever the inner segments pin

An index past the longest list of that level is an error; an item whose list is shorter gives nothing. Brackets on a segment that is not a list are an error too.

A key's value is used as it is: arithmetic reads it as a number (an entry that does not read as one drops out); comparisons are numeric when both sides read as numbers, otherwise on the text. Truth is a non-zero number or a non-empty text.

Lists

When an expression names several keys, their lists run together entry by entry, up to the shortest; a single value repeats along the list. An entry whose result is missing or not a finite number drops out, and a key with no value on an item gives nothing for that item.

Result - Result_Err        entry 0 with entry 0, entry 1 with entry 1, …
Result - Result[0]         every entry minus the first
Result / Nominal           Nominal is one value: divides every entry

With two axes the X and Y expressions are paired by entry, so an entry dropped on one side is dropped on the other.

Select

A second expression, evaluated per entry alongside the Draw expression; an entry is kept when it is true (non-zero, or non-empty text). It may name keys the Draw line does not.

Result_Err[3] < 0.1
$serial =~ 'HPK' && Result[3] > 51
$institution =~ 'BNL'
Result > 0                 keep the positive entries of a list, one by one

A selection made only of item fields (no lists) keeps or drops the whole item. The Cuts pane also keeps whole items — by status, institution, PID range, serial — where Select keeps entries. Both apply.

Binning

A trailing >> sets the bins and the axis ranges, as ROOT's >> name(nx,lo,hi). It must be the last thing on the line.

WriteSets
expr >> (50)50 bins, range automatic
expr >> (50, 30, 60)50 bins from 30 to 60
expr >> (50, , 60)a blank bound stays automatic
y : x >> (40, 0, 1, 20, 30, 60)X 40 bins 0–1, Y 20 bins 30–60; (nx,lo,hi,ny) leaves Y's range automatic
expr >> hpk(50, 30, 60)the same, and names the series “hpk” in the legend

The Bins box and the range boxes of the chart change together with it: editing one edits the other, and at least 2 bins are needed. The ranges also set the axis limits of a scatter or heat map.
